Questions for the owner (not decided, my recommendation in brackets)
1. After the member answers, the Operator forwards or ignores the message by hand, as today. (Recommended: yes, nothing automatic.)
2. The member answers with the normal Reply button, as after "Ask member to rewrite". (Recommended: yes.)
3. The member's text is English-only, like the existing rewrite request (which has no Spanish today). Do you want a Spanish text for Spanish-speaking members? (Spanish would be ours to write.)
4. Which earlier statement is quoted? The message is about ANOTHER member's listing, so the statement is on the SENDER's own listing(s), and a member can have several listings and two ticks on one. (Recommended: the Operator chooses from the sender's ticks shown; with none, the button is not offered.)
5. The date: the system holds ONE date per listing, the day the member last confirmed the whole listing, not the day each sentence was first stated. If the member edited anything later, "On 3 Nov" would be that later day. Is that acceptable, or must the real date of each sentence be kept?
