Performance: 3 RLS lines that re-evaluate per row, 4 unindexed foreign keys (minor at this size).
- Cost of change: every merge needs ~45-60 min of live CI; on 19-21 Nov three PRs were wasted by tests that held on staging but not on live.

## How we avoid wasting time and usage
- One owner decision per block; one build batch per phase; no PR opened without BATCH GO.
- Every test must hold on staging AND live; supervisor reads the push-to-main log, not only the PR.
- No tooling work unless something is broken. Cheaper CI wins first: no re-run of a run in progress, one PR per concern, long waits done by polling not by chatting.
- Rule 13 stays: list preconditions and check each with a tool before any switch, setup or migration.
