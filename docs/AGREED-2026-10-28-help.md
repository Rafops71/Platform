# Help and the language switch (2026-10-28)

The owner's words, on the same day: members and Operators need a Help /
questions section, in English and Spanish, for when they hit a snag; it is
built before the soft launch, and the films will point to it. The language
switch on the pages before signing in goes in a corner, not above the
centred box.

- **Help (checklist Item 76).** 14 member questions in English and Spanish
  (js/help.js, the help.* keys): a Help tab inside the platform, and
  help.html, linked from the sign-in page, for people who cannot get in.
  Each answer was checked against the screens' own wording. The Operator's
  console has a Help tab with 9 questions, in English like the rest of
  that console.
- **Language switch** in the top-right corner of the sign-in, register,
  reset, Terms and Help pages. It had been above the box, because the
  switch's own code replaced the class that placed it; it now adds its
  class instead.
